# ADR 0006 — Alcance y decisiones de ambigüedad en v0.1.0

- **Estado:** aceptada
- **Fecha:** 2026-11-14

## Contexto

La SPEC deja varios detalles abiertos para la primera implementación.

## Decisión

(1) `setup` sin `--no-claude` avisa que el onboarding con Claude llega en v0.2.0 y usa el cuestionario de terminal. (2) `capture`, `wt integrate`, `wt night`, `self update` y `doctor --fix` existen como comandos reservados que salen con error explicando el hito. (3) `macos-aggressive` existe como módulo vacío no habilitado. (4) Las skills no completas llevan `status: draft`. (5) `plan` usa los mismos runners en `dryRun`: las consultas de solo lectura (`query`) se ejecutan; todo lo demás se omite. (6) El filtro de `capture` ya existe y está probado aunque el comando llegue en v0.2.0.

## Consecuencias

Cada hito posterior solo añade código sobre la estructura ya creada.
