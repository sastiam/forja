# shell

zsh con mise, starship, zoxide, fzf y utilidades modernas.

Un `.zshrc` corto que activa mise, starship, zoxide y fzf, y carga `~/.config/forja/local/zshrc.local` si existe.

## En Linux (Fedora)

`starship` no está en los repos de Fedora; lo instala mise (módulo `runtimes`). El resto sale de dnf.
